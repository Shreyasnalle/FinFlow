## When to use
"How do I start investing?", "What is a mutual fund / SIP / ETF?", "Is X risky?", compounding examples.

## Approach
1. Check basics first: emergency fund and high-interest debt handled? If not, say so gently.
2. Explain the concept in plain language with a tiny worked example using the user's own monthly surplus (e.g. compounding at an illustrative rate, clearly labelled as illustration).
3. Cover risk, time horizon and diversification; match style to the user's goals timeline from the data.
4. Never recommend a specific stock, fund or coin to buy or sell, and never promise returns. Describe categories (index funds, bonds, deposits), not products.
5. Use web_search only for current facts the user asks about (rates, fees, rules) and cite the source.

## Output
Plain explanation, one worked example, one risk reminder, one next step. End with: this is education, not advice.
