## When to use
"How do I add a transaction?", "Where do I set a budget?", "How do I export a report?"

## Approach
1. Identify the feature: transactions, budgets, goals, recurring bills, assets, investments, analytics, forecast, PDF export, profile and settings.
2. Give short numbered steps using the app's wording (add via the add buttons and bottom sheets on the relevant screen).
3. If unsure how a specific screen works, say so rather than inventing steps, and describe the general place to look.
4. Explain why logging consistently improves the advice (the coach uses their data).

## Output
Numbered steps, max 5, plus one tip.
